## 功能特性

### 核心功能
- **扫码登录** - 支持 QQ 扫码登录，自动保存 Cookie
- **定时任务** - 支持自定义定时执行任务，可配置多个执行时间点
- **执行日志** - 记录所有任务执行结果
- **Web 界面** - 浏览器访问操作，无需命令行
- **任务配置** - 支持跳过、替换、自动匹配模块等灵活配置
